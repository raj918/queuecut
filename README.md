# QueueCut — Indian Salon Discovery & Digital Queue-Booking Platform

> **Tagline**: Book your turn. Skip the wait.  
> **Showcase Location**: Kanpur, Uttar Pradesh, India

QueueCut is a full-stack bare React Native CLI mobile application with a production Node.js/Express/TypeScript backend, Prisma ORM, Supabase PostgreSQL, Supabase Realtime live sync, and Firebase Cloud Messaging push notifications.

---

## 💈 Features at a Glance

### Customer Experience
- **GPS-Powered Nearby Discovery**: Discovers verified salons within **500 metres** (expandable to 1km, 3km, 5km) sorted by geodesic distance.
- **Interactive OpenStreetMap Discovery**: MapLibre map with open vector tiles, user location pin, salon markers, and preview bottom sheets.
- **Multi-Service Selection**: Select haircuts, beard styling, hair spa, or facials with combined price and duration calculation.
- **Stylist Preference**: Choose "Any Available Barber" for fastest turnaround or pick a specific stylist.
- **Atomic Token Allocation**: Receives official sequential token (e.g. `Q-001`, `Q-002`) generated by the backend engine.
- **Live Queue Tracking**: Displays customers ahead, estimated remaining minutes, barber status, and real-time updates.
- **Push Notification Alerts**: Instant heads-up alerts for token confirmation, turn approaching, barber calling, and service completion.

### Salon Owner Management
- **Live Business Dashboard**: Today's active queue, currently in chair, completed sessions, and estimated revenue.
- **Queue Controls**: Call next customer, start service, complete service, skip, mark no-show, pause/resume incoming bookings.
- **Unified Walk-in Reception Engine**: Front-desk physical walk-in entry that feeds the same atomic token sequence.
- **Service & Staff Management**: Add/edit pricing and durations, manage qualified staff, and track staff breaks.
- **Transparent Commission Ledger**: Automatic 5% platform fee on completed online bookings; walk-in customers are 100% commission-exempt (0%).

## 🚀 Step-by-Step Local Setup & Execution

### Prerequisites
- Node.js >= 18 (Tested on v26.13)
- OpenJDK 17
- Android SDK (Environment variable `ANDROID_HOME` configured)

### 1. Install Dependencies
```bash
# Install backend dependencies
cd backend
npm install

# Install mobile dependencies
cd ../apps/mobile
npm install
```

### 2. Configure Backend Environment
Copy `backend/.env.example` to `backend/.env` and update your PostgreSQL connection:
```bash
cp backend/.env.example backend/.env
```

### 3. Generate Database Schema & Seed Data
```bash
cd backend
npx prisma generate
npx prisma db push
npm run seed
```
*This populates Kanpur with 10 diverse salons across Civil Lines, Swaroop Nagar, Kakadeo, Kidwai Nagar, and Gumti No. 5 with live tokens.*

### 4. Run the Backend Server
```bash
cd backend
npm run dev
```
The REST API will start at: `http://localhost:5000/api`  
Health check endpoint: `http://localhost:5000/api/health`

### 5. Run the Mobile App on Android

#### On Physical Android Device:
1. Enable **Developer Options** and **USB Debugging** on your Android phone.
2. Connect your phone via USB (`adb devices` should list your device).
3. If connecting to a local backend on your computer, run:
   ```bash
   adb reverse tcp:5000 tcp:5000
   ```
4. Start Metro and launch:
   ```bash
   cd apps/mobile
   npm run start
   ```
   In a second terminal:
   ```bash
   cd apps/mobile
   npm run android
   ```

#### On Android Emulator:
```bash
cd apps/mobile
npm run android
```
*(The mobile app defaults to `http://10.0.2.2:5000/api` for emulator networking).*

## 📦 Generating an Android Release Build (APK)

To build a standalone production APK for installation on physical Android phones:

```bash
cd apps/mobile/android
./gradlew assembleRelease
```
The output APK is generated at:
`apps/mobile/android/app/build/outputs/apk/release/app-release.apk`

## 🌐 Deploying Backend to Vercel

1. Push your repository to GitHub.
2. In the [Vercel Dashboard](https://vercel.com), import your repository.
3. Configure the build command:
   ```bash
   cd backend && npm run prisma:generate && npm run build
   ```
4. Add your production environment variables (`DATABASE_URL`, `JWT_SECRET`, etc.).
5. Deploy! Detailed steps are in [`docs/deployment.md`](./docs/deployment.md).
